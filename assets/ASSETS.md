Every file FreeCut ships (fonts, icons, LUTs, stickers, sounds, test media) is
listed here with its source and license. Only assets we created ourselves or
that carry a license compatible with GPL-3.0-or-later are allowed (for example
OFL fonts, CC0 media, MIT/ISC icon sets).

Never add anything taken from CapCut or any other proprietary editor.
